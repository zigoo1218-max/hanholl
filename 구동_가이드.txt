======================================================================
     한홀중학교 학생 영상 성과발표회 3D 전시관 - 윈도우 구동 및 운영 가이드
======================================================================

본 문서는 윈도우(Windows) 기반 키오스크 PC 환경에서 3D 전시관 서버를 안전하게 실행하고,
영상이나 작품 소개글 등의 콘텐츠를 static 빌드 과정 없이 실시간으로 운영/관리하는 방법을 안내합니다.

----------------------------------------------------------------------
1. 최초 설치 방법 (윈도우 키오스크 PC로 이관)
----------------------------------------------------------------------
① 현재 개발된 전시관 전체 폴더(school-showcase-gallery)를 통째로 압축하거나 복사하여,
   키오스크 PC의 원하는 경로(예: C:\exhibition\ 또는 바탕화면)에 붙여넣습니다.
   ※ 주의: "public" 폴더만 옮겨서는 구동되지 않으며, 전체 폴더가 필요합니다.

② 키오스크 PC에 Node.js가 설치되어 있어야 합니다.
   - 만약 설치되어 있지 않다면 아래 공식 홈페이지에서 LTS 버전을 설치해 주세요.
   - 다운로드 링크: https://nodejs.org
   ※ Node.js 설치가 끝나면 반드시 PC를 한 번 재부팅하거나 명령 프롬프트를 재실행해 주세요.

----------------------------------------------------------------------
2. 원터치 서버 및 전시관 실행 방법
----------------------------------------------------------------------
① 폴더 내에 위치한 [전시장_원터치_구동.bat] 파일을 더블 클릭하여 실행합니다.
② 본 프로그램은 다음과 같은 동작을 원터치로 자동 수행합니다:
   - 종속성 패키지(node_modules)가 없는 경우 자동 설치 (1회)
   - 최적화 빌드 결과(.next)가 없는 경우 최초 빌드 자동 컴파일 (1회)
   - Next.js 로컬 웹서버를 포트 3000(http://localhost:3000)에서 백그라운드로 안전 기동
   - 서버 준비 완료 후, 크롬(Chrome) 브라우저를 주소창과 창 조작 버튼이 모두 숨겨진
     [Kiosk Mode (전체화면)]로 자동 오픈하여 전시 화면을 즉시 송출합니다.
   ※ 관람객이 주소창을 임의로 조작하거나 다른 사이트로 이탈하는 위협을 완벽히 차단합니다.

----------------------------------------------------------------------
3. 운영 중 동영상 및 작품 정보 실시간 갱신 방법 (무빌드 즉시 반영)
----------------------------------------------------------------------
전시관 가동 중에 작품 영상이나 작품 제목, 팀명, 소개글을 변경하고 싶을 때는 
정적 빌드나 서버 재부팅이 전혀 필요 없는 [무빌드 즉시 반영] 방식으로 간편하게 관리합니다.

폴더 내 [public] -> [media] 폴더로 들어가서 각 조별 폴더(team1 ~ team8)를 관리합니다:
(※ 5조의 경우 team5a, team5b로 세분화되어 총 9개 폴더가 존재합니다)

■ 동영상 교체하기:
  해당 조별 폴더 안에 새 동영상 파일을 넣어주되, 파일명을 반드시 [video.mp4]로 통일해 줍니다.
  - 경로 예시: public/media/team1/video.mp4
  ※ 덮어쓰고 옮기는 순간 즉각 전시관에 반영되며, 브라우저 캐싱을 무력화하도록 설계되어
     새로고침 즉시 새로운 영상이 감상됩니다.

■ 작품 썸네일(표지) 이미지 교체하기:
  해당 조별 폴더 안에 새 이미지 파일을 넣어주되, 파일명을 [thumbnail.jpg]로 통일해 줍니다.
  - 경로 예시: public/media/team1/thumbnail.jpg
  ※ 움직이는 GIF 표지를 적용하고 싶다면 [thumbnail.gif]로 교체해도 완벽히 연동됩니다.

■ 작품 텍스트 정보(제목, 소개글, 팀원명) 수정하기:
  해당 조별 폴더 내부의 [info.json] 파일을 메모장으로 열어 텍스트를 수정하고 저장합니다.
  - 경로 예시: public/media/team1/info.json
  - JSON 텍스트 서식 예시:
    {
      "title": "여기에 작품 제목 입력",
      "caption": "여기에 작품 상세 설명이나 소개글 입력",
      "studentNames": ["팀원1", "팀원2", "팀원3"]
    }
  ※ 메모장에서 한글을 수정한 뒤 저장할 때, 인코딩을 반드시 [UTF-8]로 지정하고 저장해 주세요.
     인코딩이 다를 경우 한글이 깨져 보일 수 있습니다.

----------------------------------------------------------------------
4. 전시관 안전 종료 방법
----------------------------------------------------------------------
① 크롬 키오스크 전체화면 종료:
   - 키보드의 [Alt] 누른 채로 [F4] 단축키를 눌러 브라우저 전체화면을 안전하게 종료합니다.
② Next.js 웹서버 종료:
   - 서버를 가동할 때 백그라운드에서 열렸던 검은색 명령 프롬프트(CMD) 창을 [X] 단축키로 닫거나
     명령창에서 [Ctrl + C]를 누르고 'Y'를 입력하여 서버 기동 프로세스를 완전하게 해제합니다.
