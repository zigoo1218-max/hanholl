# 한홀중학교 3D 성과발표회 갤러리 요구사항

## 1. 프로젝트 목표

학생들이 팀 단위로 제작한 영상을 성과발표회에서 관람객에게 보여주는 3D 전시관을 구현한다.
일반적인 카드형 웹 갤러리가 아니라, 관람객이 전시 공간을 직접 이동하면서 작품을 선택하는 경험을 제공한다.

학교는 공공기관의 성격을 가지므로 시각 디자인은 신뢰감, 명확한 안내, 절제된 움직임을 우선한다.

## 2. 확정 요구사항

### 행사 운영

- 노트북 1대와 프로젝터를 사용한다.
- 발표자가 순서대로 재생하는 방식이 아니라 관람객이 직접 조작한다.
- 키보드와 마우스를 기본 입력 장치로 사용한다.
- 구현 PC와 전시용 PC는 다르므로 프로젝트 전체를 다른 PC로 이관할 수 있어야 한다.
- 인터넷 연결 없이도 작품 관람이 가능해야 한다.

### 작품 콘텐츠

- 초기 작품 수는 약 9~10개다.
- 향후 최대 20개 작품까지 구조 변경 없이 확장할 수 있어야 한다.
- 작품 영상은 720p~1080p이며 최대 길이는 약 5분이다.
- 작품은 개인이 아니라 팀 단위로 제작한다.
- 작품별로 아래 정보를 표시한다.
  - 팀 표기: `1조`~`8조`, `5A조`, `5B조`
  - 참여 학생 이름 목록
  - 작품 제목
  - 작품 캡션
  - 썸네일
  - 영상 파일

### 학교 상징

공식 학교 페이지의 상징 정보를 디자인에 절제해서 반영한다.

- 학교명: 한홀중학교
- 비전: 서로를 밝히며 함께 성장하는 한홀
- 교육목표: 존중, 협력, 성장
- 교목: 소나무
- 교화: 수국
- 교표 의미: 원형과 사람을 형상화한 H를 통해 화합을 표현
- 공식 출처:
  - https://www.goegh.kr/hanholl-m/cm/cntnts/cntntsView.do?cntntsId=1909&mi=11035

### 학교 홍보영상

- 사용자 제공 파일:
  - `/Users/z9/Downloads/학교_전경_이미지인데_드론뷰로_학교_주변을_돌면서_보여.mp4`
- 파일 크기 확인 결과: 약 4.2MB
- 대표 프레임 확인 결과: 학교 전경과 주변 환경이 한눈에 보이는 드론뷰 영상
- 활용 방향:
  - 입장 화면의 선택형 배경 영상으로 사용한다.
  - 음소거 자동 재생을 기본값으로 한다.
  - `영상 건너뛰기` 또는 즉시 입장 수단을 제공한다.
  - 영상 재생 실패 시에도 전시관 입장은 정상 동작해야 한다.
  - 3D 공간 내부에서는 재생하지 않는다.

## 3. 디자인 원칙

- 공공기관형 UI: 네이비, 흰색, 중립 회색을 기반으로 한다.
- 학교 상징색은 보조적으로만 사용한다.
  - 소나무: 절제된 녹색
  - 수국: 절제된 보라색
- 과도한 장식, 빠른 카메라 이동, 강한 시각 효과를 피한다.
- 프로젝터 환경에서 제목, 조작 안내, 작품 캡션을 읽기 쉽게 구성한다.
- 3D 효과보다 작품 접근성과 행사 운영 안정성을 우선한다.

## 4. 비기능 요구사항

### 성능

- 초기 화면에서 작품 영상을 미리 로드하지 않는다.
- 전시관에서는 작품 썸네일만 로드한다.
- 선택된 작품만 영상 플레이어에서 로드한다.
- 작품 수가 20개로 늘어나도 같은 구조를 유지한다.

### 접근성 및 대체 경로

- 화면에 키보드 및 마우스 조작 안내를 표시한다.
- 3D 조작이 어려운 관람객을 위해 2D 작품 목록 보기를 제공한다.
- WebGL 미지원 환경에서는 2D 목록으로 진입할 수 있어야 한다.
- 영상 파일이 없거나 재생되지 않으면 명확한 안내 메시지를 표시한다.

### 이관성

- 작품 영상, 썸네일, 메타데이터를 앱 폴더 안에서 관리한다.
- 앱 전체 폴더 복사로 다른 PC에 이관할 수 있어야 한다.
- 운영 문서에 전시 PC 설치, 빌드, 실행, 영상 교체 절차를 기록한다.

## 5. 현재 미결정 사항

아래 항목은 구현을 막지 않으며 샘플 값으로 시작할 수 있다.

- 행사 공식 명칭
- 실제 작품 제목과 캡션
- 실제 팀별 학생 이름

- 학교 로고 원본 파일 제공 여부
